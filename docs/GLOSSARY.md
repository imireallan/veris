# GLOSSARY — Agent Engineering / Veris

- ReAct: Reason + Act agent loop (plan, call tool, observe, update).
- RAG: Retrieval-Augmented Generation; used in Veris `knowledge/` module.
- LangChain: Agent framework selected; paired with FastAPI (`ai_engine/`).
- TDi: Target consultancy client (demo audience).
- Agent layer: Generic `agent/` module (provider-agnostic) extracted from Veris.
- Industry path: Build Veris-specific first → extract generic ESG agent modules.
- `ai_engine/chat`: Entry point for ReAct agent (stub → production).
